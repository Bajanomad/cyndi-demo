# Cyndi Williams Demo (Designs by David)

A working demonstration website for Cyndi Williams, Selling Sur
Real Estate Co., built Nov 19 2026 at David's order: an old
school real estate site she can log into and stress test.

- Classic layout: masthead, hero, featured listings, filterable
  listings grid, about, contact. Black, white, cream and gold.
- All 34 of her active MLS listings with real prices, specs,
  photos (MLS CDN) and full descriptions, scraped Nov 18 2026.
- Contact routes are real: her WhatsApp +52 624 158 8650 (the
  number on her listings, not the dead one on sellingsur.com),
  phone and email.
- Admin login (footer): usernames cyndi and david, first sign
  in sets the password. Admins can edit price, status and
  featured flag per listing and add a note. Edits save to the
  shared database (Supabase project "411 Apps", table
  re_demo_state) and show for every visitor.
- Repo Bajanomad/cyndi-demo, hosted on Vercel per David's rule
  that real sites live there.
